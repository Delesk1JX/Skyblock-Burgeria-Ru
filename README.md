# Skyblock Burgeria-Ru

Информация: Перевод квестов в сборке Skyblock Burgeria (3.0 hotfix2) Ссылка на [сборку](https://www.curseforge.com/minecraft/modpacks/skyblock-burgeria)

Установка: Пример для Prism Launcher:

Скопировать с заменой файлы в корневую директорию сборки. Например, C:\Users\user\AppData\Roaming\PrismLauncher\instances\SkyBlockBurgeria\minecraft

После запустите игру и проверьте работу перевода.

Если найдёте какие-то ошибки, можете сообщить о них мне в дискорд:narik_20

Для перевода модов использовал:

[RTF Extension](https://modrinth.com/resourcepack/rtf-extension)
